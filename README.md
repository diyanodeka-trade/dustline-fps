**DUSTLINE** is a round-based tactical FPS built in Three.js featuring responsive gunplay, AI teammates and enemies, bomb defusal mechanics, weapon purchases, and WebAudio procedural sound effects.

## Run it

```bash
node serve.ts
```
Then open `http://localhost:8080` in your browser.
